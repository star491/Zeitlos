# Injection moulding specification (PP)

One PP part, one shot. Half A and half B are moulded open and joined by a rear living hinge, and the cap flap is hinged to the nose of half A. Based on v20, with the print-only features removed.

## Material

| Item | Value |
| --- | --- |
| Polymer | PP homopolymer, living-hinge grade, MFI 12-25 |
| Shrinkage allowance | 1.6 % (confirm on first trial) |
| Part weight | About 8.5 g |

Flex both hinges a few times right after ejection.

## Design changes for moulding

Everything else stays as v20.

| Feature | 3D print (v20) | Moulded |
| --- | --- | --- |
| Flap | 0.45, standing upright, free fold | 0.60, moulded flat at the bottom, 0.30 hinge web at the root; holes re-placed for the tight fold |
| Holes in flap | Pointed (teardrop) tops | Plain slot and rectangles |
| Lock protrusions | 40 deg sloped underside | Square underside, formed by a slide |
| Rear hinge plate | 0.80 solid | 0.30-0.35 hinge web, R0.3 shoulders |
| Nose fills | Squared to the bed for printing | Removed; original rounded nose |
| Snap slits | 0.20 | 0.50 minimum |
| Draft and corners | None | 1 deg outside, 0.5 deg bore, R0.2 min inside corners; core out walls over 2.2 |

## Mould configuration

2-plate cold runner, 1 cavity, about 65 components. The parting line is on the mating face of the halves; the cavity forms the outside and the core the inside. One tab gate on half B by the rear hinge, so the melt crosses each hinge straight across in one direction.

| Component | Qty |
| --- | --- |
| Mould plates (clamp x2, cavity, core, support, ejector x2, spacers x2) | 9 |
| Cavity and core inserts | 2 |
| Guide pillars, bushes, return pins | 12 |
| Sprue bushing, locating ring | 2 |
| Side slides (nose lock; S-clip) with angle pins, heels, wear plates, retainers | 10 |
| Lifters (snap hooks) | 6 |
| Ejector pins | About 20 |
| Support pillars | 4 |

If the snap undercut is 0.3 or less, the part can be bumped off without lifters (about 59 components).

## Tolerances and fits

General: +/-0.05 up to 6 mm, +/-0.10 to 30, +/-0.20 to 120, +/-0.35 above; hinge webs +/-0.03.

| Fit | Clearance |
| --- | --- |

| Refill end play | 0.2-0.4 |
| Lock hole on stem | 0.10 per side |
| Head over hole edge | 0.40 per end |
| Nib hole to tip | 0.30 radial |
| Closed arch to nib | 0.8 min |
| Front gap between halves | 0.10 |

The shrinkage, part weight, mould component count and tolerance grade are working estimates; confirm them with the moulder.
